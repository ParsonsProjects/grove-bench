# Keyboard Shortcuts

## Tab Navigation

| Shortcut | Action |
|----------|--------|
| `Alt+1` | Switch to Activity tab |
| `Alt+2` | Switch to Changes tab |
| `Alt+3` | Switch to Checkpoints tab |
| `Alt+4` | Switch to Terminal tab |

## Search & Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+F` | Search in Activity tab |
| `Ctrl+R` | Open conversation finder (quick-switch between conversations) |

## Agent Controls

| Shortcut | Action |
|----------|--------|
| `Alt+M` | Cycle agent mode (Code / Plan / Edit / Auto / Read-safe) |
| `Alt+E` | Cycle effort level (Low / Medium / High / Extra / Max, as offered by the current model) |
| `Alt+T` | Toggle thinking (On / Off; fixed levels on Haiku 4.5; not shown on models that always think) |

## General

| Shortcut | Action |
|----------|--------|
| `Enter` | Send message |
| `Shift+Enter` | New line in prompt editor |
| `Escape` | Close panel / Stop agent |
