# Keyboard Shortcuts

## Help

| Shortcut | Action |
|----------|--------|
| `F1` | Open Help (the **?** in the title bar does the same) |

## Tab Navigation

| Shortcut | Action |
|----------|--------|
| `Alt+1` | Switch to Thread tab |
| `Alt+2` | Switch to Changes tab |
| `Alt+3` | Switch to Checkpoints tab |
| `Alt+4` | Switch to Terminal tab |
| `Alt+5` | Switch to Preview tab |

## Search & Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+F` | Search in Thread tab |
| `Ctrl+R` | Open conversation finder (quick-switch between conversations) |
| `Ctrl+N` | New conversation draft (in the open conversation's project) |
| `Ctrl+Shift+T` | Reopen the last conversation you marked completed |
| `Ctrl+B` | Open or close bookmarks |
| `Ctrl+L` | Go to the address bar (Preview tab) |

Inside a Preview page, browser keys work as usual (`F5`, `F12`, `Alt+Left`). See [Preview tab](preview-tab.md#keys-inside-the-page).

## Agent Controls

| Shortcut | Action |
|----------|--------|
| `Alt+M` | Cycle agent mode (Ask / Plan / Edit / Auto / Read-safe) |
| `Alt+E` | Cycle effort level (Low / Medium / High / Extra / Max, as offered by the current model) |
| `Alt+T` | Toggle thinking (On / Off; fixed levels on Haiku 4.5; not shown on models that always think) |

## General

| Shortcut | Action |
|----------|--------|
| `Ctrl+,` | Open or close Settings |
| `Enter` | Send message |
| `Shift+Enter` | New line in prompt editor |
| `Escape` | Close a popup, picker or panel |
